# Browser calculator

A small calculator interface built with HTML, CSS, and vanilla JavaScript. It supports digits, decimals, parentheses, the four basic operations, clearing the display, and calculating a result. The controls can be used with a mouse or keyboard.

## Run locally

Open `Calculatrice/index.html` in a browser. No installation or build step is required.

## How it works

`Calculatrice/style.js` maps button clicks and keyboard key codes to the display. Press **C** to clear and **=** or Enter to evaluate the expression. An invalid expression displays an error message.

This is a learning exercise and a browser demo; it is not intended for financial or scientific calculations.
